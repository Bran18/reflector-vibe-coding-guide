# Reflector Vibe Coding Guide

A practical guide to building Stellar applications with an AI coding assistant and the Reflector skill.

## Read the guide

[Vibe Coding with Reflector](reflector-vibe-coding-guide.md) includes copyable prompts for a first price reader, UI integration, Soroban contracts, troubleshooting, and implementation reviews.

## Project status

The Markdown guide is the starting point for a documentation website. Website implementation and hosting are not set up yet.

## Contributing

Propose corrections and examples through issues or pull requests. For technical updates, include an official source, applicable dependency or contract version, and any verification performed. Keep deployment-specific configuration explicit and never commit secrets.
